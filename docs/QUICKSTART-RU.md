# Быстрый старт

Опубликованный стабильный релиз — **0.4.1**, с пакетами ARM64 и MIPS soft-float. Установка нового роутера и установка только панели — отдельные режимы.

## Новый роутер

Первый поддержанный вариант: **Ultra KN-1811 / KeeneticOS5.01.C.6.0-1 / linux/arm64**, рабочий Entware `/opt`, один private IPv4 bridge и один WAN, без уже установленных XKeen/панели/резолвера и host/custom DNS-исключений. Нужны `curl`, `jq`, `sha256sum`, `flock`, `stat`, `opkg`, 128 MiB свободной памяти и места. [Полная матрица и восстановление](FRESH-KEENETIC.md).

```sh
xkeen_installer=$(curl -fsSL https://github.com/popiposter/xkeen-control/releases/download/v0.4.1/install.sh) && sh -c "$xkeen_installer" -- --setup
```

По запросу вставьте подписку или VLESS-узел. GNU tar, stock XKeen2.1/Xray, панель и независимый DNS готовятся установщиком; эталон RU selective включает torrent DIRECT. Вся HOME-сеть подключается после проверок VPN/DNS и сохранения политики/автозапуска. Откройте домашний URL панели из итогового сообщения; первый пароль указан в терминале. Приватную ссылку не добавляйте в команду.

Fresh hardware/LAN/IPv6/отказ upstream ещё не прошли отдельную аппаратную приёмку. Другие модели/прошивки и существующая/частичная установка не поддерживаются этим режимом.

## Только панель поверх XKeen

Для Keenetic linux/arm64 или linux/mipsle soft-float с Entware и уже работающим штатным XKeen/Xray:

**Ultra KN-1810 использует MIPS.** Для Entware `mipsel-3.4`/`mipsel-3.4_kn` установщик0.4.1 выбирает MIPS-пакет автоматически. Перед установкой сохраните частную резервную копию и проверьте существующий watchdog по [инструкции KN1810](MIPS-KEENETIC.md). Аппаратная проверка этого назначения ещё не завершена. `--setup` для KN1810 и существующих установок не поддерживается.

```sh
xkeen_installer=$(curl -fsSL https://github.com/popiposter/xkeen-control/releases/download/v0.4.1/install.sh) && sh -c "$xkeen_installer"
```

Этот режим не создаёт HOME policy/DNS и не применяет эталон. Первый пароль выводится в терминал; существующий пароль сохраняется. Default listener — `127.0.0.1:8787`; откройте туннель с компьютера:

```sh
ssh -L 8787:127.0.0.1:8787 root@<адрес-роутера>
```

Откройте **http://localhost:8787**. Для постоянного доступа выберите один доверенный LAN-адрес в настройках панели. Не открывайте панель в WAN. Уже управляемую панель обновляйте подписанным self-update в System → Panel; `--setup` поверх неё не запускается.

## Первые действия

1. После `--setup` источник уже добавлен: проверьте Nodes. При установке только панели добавьте подписки или VLESS/REALITY-ключи сами. Ручное отключение сохраняется при обновлении; WL, Россия и Беларусь выключены по умолчанию.
2. Настройте Routing/DNS и другие конфиги в форме или редакторе JSON/JSONC. Сохраняйте черновики, форматируйте текст, используйте undo/redo.
3. Save проверяет полный Xray-конфиг. Общий набор сохранённых изменений применяется явным Apply/перезапуском. До Apply можно Discard; после — явно вернуть предыдущую конфигурацию. HTTP202 ещё не означает успешный перезапуск.
4. Запустите тест скорости и примените свежую рекомендацию при необходимости. Тест не меняет конфиги сам; после применения Xray выбирает внутри пула, а не постоянно закрепляет первую строку рейтинга.
5. Для сервисов, компонентов и расписаний используйте Native XKeen commands. Консоль показывает штатный вывод и вопросы интерактивных команд.
6. Сохраните зашифрованный экспорт. Перенос использует проверяемый импорт и сопоставление интерфейсов; импорт не перезапускает сервис автоматически.
7. Telegram включается отдельно с вашим токеном, одним разрешённым пользователем и чатом.

## DNS и проверка клиентов

Редактор DNS Xray и независимый LAN DNS — разные части. При установке только панели LAN DNS требует отдельно установленного резолвера и DNS-профиля Keenetic. Fresh `--setup` готовит их в поддержанном варианте; далее обычная панель синхронизирует доменные правила. DIRECT DNS не зависит от Xray; VPN DNS не переходит в DIRECT при отказе VPN.

Проверяйте прямой доступ и VPN с отдельного LAN-клиента без локального VPN/proxy. При установке только панели политика клиентов настраивается отдельно в соответствии со штатным режимом XKeen; fresh `--setup` готовит и проверяет HOME policy/DNS сам. Публикация релиза не означает его установку на конкретный роутер.
