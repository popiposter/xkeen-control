# Быстрый старт

Нужны Keenetic linux/arm64, работающий Entware `/opt` и штатный XKeen с Xray. Сначала установите и настройте XKeen его официальным способом. Панель не заменяет его установщик, компоненты, перехват трафика или cron.

Для нового роутера используйте [порядок установки](FRESH-KEENETIC.md): Entware и выбранный GNU tar → официальный XKeen/Xray → политика выбранных клиентов → панель поверх → независимый DNS и профиль Keenetic → конфигурация/подписки → явное применение. [План единого мастера](../plan/feature-fresh-router-setup-1.md) и [эталон RU selective v1](../config/presets/README.md) подготовлены отдельно; автоматическая установка всей связки и выбор эталона в UI пока не реализованы.

## Установка и вход

Опубликованный стабильный релиз — **0.3.1**:

```sh
sh -c "$(curl -fsSL https://github.com/popiposter/xkeen-control/releases/download/v0.3.1/install.sh)"
```

Первый пароль панели выводится в терминал установщика; повторная установка сохраняет существующий пароль. По умолчанию панель слушает только `127.0.0.1:8787`. Откройте туннель с компьютера:

```sh
ssh -L 8787:127.0.0.1:8787 root@<адрес-роутера>
```

Откройте **http://localhost:8787**. Для постоянного доступа выберите один доверенный LAN-адрес в настройках панели. Не открывайте панель в WAN.

## Первые действия

1. Добавьте подписки или VLESS/REALITY-ключи в Nodes. Ручное отключение сохраняется при обновлении; WL, Россия и Беларусь выключены по умолчанию.
2. Настройте Routing/DNS и другие конфиги в форме или редакторе JSON/JSONC. Сохраняйте черновики, форматируйте текст, используйте undo/redo.
3. Save проверяет полный Xray-конфиг. Общий набор сохранённых изменений применяется явным Apply/перезапуском. До Apply можно Discard; после — явно вернуть предыдущую конфигурацию. HTTP202 ещё не означает успешный перезапуск.
4. Запустите тест скорости и примените свежую рекомендацию при необходимости. Тест не меняет конфиги сам; после применения Xray выбирает внутри пула, а не постоянно закрепляет первую строку рейтинга.
5. Для сервисов, компонентов и расписаний используйте Native XKeen commands. Консоль показывает штатный вывод и вопросы интерактивных команд.
6. Сохраните зашифрованный экспорт. Перенос использует проверяемый импорт и сопоставление интерфейсов; импорт не перезапускает сервис автоматически.
7. Telegram включается отдельно с вашим токеном, одним разрешённым пользователем и чатом.

## DNS и проверка клиентов

Редактор DNS Xray и независимый LAN DNS — разные части. Последний требует отдельно установленного стандартного резолвера и DNS-профиля Keenetic. Панель синхронизирует доменные правила, но не устанавливает эту инфраструктуру. DIRECT DNS не зависит от Xray; VPN DNS не переходит в DIRECT при отказе VPN.

Проверяйте прямой доступ и VPN с отдельного LAN-клиента без локального VPN/proxy. Политика Keenetic зависит от выбранного штатного режима XKeen, не от установщика панели. Публикация релиза не означает его установку на конкретный роутер.
